# 買い物リスト

紙とペン風の、日本語の買い物リストアプリ（v1）。ブラウザだけで動き、データは**この端末の中（localStorage）だけ**に保存されます。サーバー・アカウント・広告・AI API はありません。

## 何ができるか
- **買い物リスト**: お店ごとのカードに品物を表示。丸をタップで買った印（取り消し線）→ 少し待って「今日買ったもの」へ移動。「戻す」で元に戻せます。お店で絞り込み、「売り場順」で野菜→肉→魚…とスーパーを歩く順に並べ替え（設定は保存）。
- **削除**: 品の「消す」は2回押すと消え、数秒「元に戻す」が出ます。チェック済みは件数を確認してまとめて削除、リストを空にするときも確認します。マイページの購入履歴は1件ずつ、またはすべて（件数と赤いボタンで確認）消せます。履歴を消しても、品名のまとめ（別名・名前の学習）と値段のメモは残ります。
- **入力して追加**: お店を選んで入力、Enter で連続追加。直近3件の「取り消す」、＋メモ付き。打ち始めると、買ったことのある品名（別名やまとめのあとの名前）が候補に出ます。ひらがな・カタカナ・半角と全角の違いでも当たります。候補は最大6件で、押すとその名前が入ります。使わずに、今までどおり自分で書くこともできます。
- **話して追加**: マイクボタン（Web Speech API・ja-JP）。「牛乳、卵、パン」「豆腐と納豆」のように区切って複数追加。非対応の端末ではマイクを隠します。
- **定期購入品**: よく買う品を登録して「リストへ」。すでにあれば知らせます。
- **値段メモ**: 追加シートの「値段（円）」（全角・「¥」「円」「,」も可）や、行の品名タップで値段を記録。**買った（チェックした）ときに**お店×商品名ごとに覚え、次に同じお店・同じ品をリストに入れると「前回1,280円」と小さく表示します（今回の値段があれば「198円」も）。
- **前回買った日**: 同じお店・同じ品を買った記録があると、行に「前回 10/28（14日前）」と薄く出します。記録がなければ出しません。買った日は30日を過ぎても残ります。
- **マイページ**: お店の追加・名前変更・並べ替え・削除（品物は「未設定」へ移動）、JSON の書き出し（ファイル保存＋コピー用テキスト）と取り込み（上書き前に確認）。購入履歴は1件ずつ、またはすべて消せます。
- **購入履歴を見る**: マイページの「購入履歴を見る」から、日付の新しい順に開けます。見出しにその日のお店と合計（値段がある品だけ。無い品は「—」で、件数を添える）を出します。右には前回の値段（無ければ出さない）。上でお店・期間（今月・先月・すべて）・品名を絞れ、条件と合計はスクロールしても残ります。品名は端末の中だけで探します。品名を押すと、その品の過去（最安のお店と平均、日付・お店・値段）を比べられます。履歴が無いときと、絞って0件のときで空の表示を分けます。この画面からは消しません。

## 使い方
1. 右下の赤いペンで品物を追加する。
2. お店で買いながら、丸をタップして済んだものを消す。
3. 買い忘れが心配なときは「今日買ったもの」を開いて「戻す」。

## 開発
Node.js 20 以上が必要です。

```
npm install
npm run dev       # 開発サーバー
npm run check     # 単体テスト（vitest）
npm run build     # dist/ に出力（base: './'）
npm run preview   # build 結果の確認
npm run e2e       # Playwright(playwright-core) による操作テスト。/opt/google/chrome/chrome を使用
npm run shots     # 390x844 @3x のスクリーンショットを shots/ に出力
```

構成: `src/state/store.js`（純粋な状態操作＋保存）、`src/lib/`（分類・アイコン・音声）、`src/data/aisles.js`（売り場の辞書）、`src/ui/`（描画）、`src/main.js`（起動とイベント）。

### 売り場の分類について
品名を正規化（NFKC・小文字・カタカナ→ひらがな）して、完全一致 → 最長の部分一致 → 「その他」の順で判定します。「豆乳」は牛乳の隣に置かれることが多いので「乳製品・卵」にしています。辞書は `src/data/aisles.js` に追記できます。

## GitHub Pages 公開の手順（説明のみ・まだ実施していません）
1. `npm run build` で `dist/` を作る（`base: './'` なのでサブパスでも動きます）。
2. `dist/` の中身を Pages の公開ブランチ（例: `gh-pages`）か、GitHub Actions の Pages デプロイで公開する。
3. 公開後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で開けることを確認する。

## Capacitor 化の予定メモ
- `npm i @capacitor/core @capacitor/cli` → `npx cap init`、`webDir` は `dist`。
- iOS/Android を追加し、`npm run build && npx cap sync`。
- 音声入力は WebView の Web Speech API が使えない場合があるので、ネイティブの音声認識プラグインへの差し替えを検討。
- localStorage は端末の掃除で消えうるため、書き出し機能の案内を残す（将来は Preferences プラグインへ）。

## データについて
すべて端末の localStorage に保存されます。リストはキー `kaimono-list-v1`、購入の履歴はキー `kaimono-history-v1` です。外部へ送信しません。読めない保存データは消さず、別のキーに控えを残して画面で知らせます。機種変更のときは、マイページの書き出し／取り込みを使ってください。
